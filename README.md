# Rajat — Personal Portfolio

Bespoke single-page portfolio website for Rajat, web designer & developer.

## Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lucide React + Motion

## Features
- Five-beat narrative arc: Hero, About, Capabilities, Process, Proof (Client Work & Templates), Contact
- High-contrast dark theme (`#080808` base, `#111111` surface, `#C7FF32` neon lime accent)
- Typography: Satoshi (display), Inter (body), Geist Mono (technical)
- Autoplaying muted video preview cards with browser frame styling
- Full-screen accessible video lightbox modal
- Split contact section with direct inbox and validation
- Clean responsive layout tested on mobile, tablet, and desktop

## Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
